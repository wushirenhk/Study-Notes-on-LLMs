## 一、选择题
### 第 1 题
**题目：** 以下关于 Reject Sampling（拒绝采样）在 RLHF 中的应用，哪项正确？
**A.** 拒绝所有奖励低于平均值的样本
**B.** 用策略模型采样多个回复，奖励模型打分，只保留高分样本用于 SFT 训练
**C.** 用于过滤训练数据中的有害内容
**D.** 在推理时拒绝不符合格式要求的输出
**答案：B**
### 解析
- **A 错误：** 拒绝采样不是简单以平均值做截断，不是直接砍掉低于均值的样本。
- **B 正确：** RLHF 里的 Reject Sampling（拒绝采样）流程：策略模型生成多条候选回复，奖励模型对每条打分，筛选高分样本，把筛选后的优质样本拿去做监督微调 SFT，是一种低成本的提升数据质量的方案，常作为 RLHF 的替代/前置方法。
- **C 错误：** 过滤有害内容是安全对齐、内容审核模块的目标，不是拒绝采样的核心作用。
- **D 错误：** 拒绝采样是训练阶段的数据筛选手段，不是推理阶段校验输出格式。
> **补充：** 拒绝采样（Rejection Sampling）在 RLHF 相关语境，也常叫 Best-of-N 采样用于数据构建，采样 N 个回答，挑奖励最高的样本作为训练数据。

### 第 2 题
**题目：** 以下关于"指令遵循"（Instruction Following）评估的描述，正确的是？
**A.** MMLU 可以直接评估指令遵循能力
**B.** IFEval（Instruction Following Eval）通过可编程验证的具体约束（如"回复必须超过 100 字"）精确评估模型遵循指令的能力
**C.** 指令遵循只能通过人工评估
**D.** PPL（困惑度）可以衡量指令遵循能力
**答案：B**
### 解析
- **A 错误：** MMLU 是知识问答/多学科能力测试，考察知识推理，不是评估指令遵循。
- **B 正确：** IFEval 专门设计了可程序自动校验的硬性约束（字数、特定格式、关键词、大小写等），自动化评估模型是否严格遵守指令要求。
- **C 错误：** 指令遵循有人工评估，也有 IFEval、AutoIF 等自动化评估方案，并非只能人工。
- **D 错误：** PPL（困惑度）衡量文本生成流畅度、对文本的预测概率，不能衡量是否遵守指令。
> **补充：** IFEval 的核心亮点：约束可代码验证，避免主观打分，专门测模型能不能严格按用户指令的规则做事，而不是只看回答内容对不对。

### 第 3 题
**题目：** 在以下 LoRA 初始化策略中，哪种是默认且推荐的？
**A.** A 和 B 均使用随机高斯初始化
**B.** A 使用随机高斯初始化，B 初始化为全零
**C.** A 初始化为全零，B 使用随机高斯初始化
**D.** A 和 B 均初始化为全零
**答案：B**
### 解析
- **A 错误：** B 不是全零，不能两个都随机高斯。
- **B 正确：** A 使用随机高斯初始化，B 初始化为全零，是 LoRA 论文原版、HuggingFace PEFT 默认推荐策略。训练初始 $\Delta W = BA = 0$，模型和基座完全一致，保证训练稳定；A 随机，保证梯度可以正常回传更新。
- **C 错误：** 写反了。
- **D 错误：** 若 A、B 全零，梯度永远为 0，参数无法学习。
> **补充：** PEFT 里 `init_lora_weights="gaussian"` 就是 A 高斯，B=0；默认 `init_lora_weights=True` 是 A 用 Kaiming 均匀，B=0，考题一般简化描述成 A 随机高斯。

### 第 4 题
**题目：** 以下关于 IA³（Infused Adapter by Inhibiting and Amplifying Inner Activations）的描述，正确的是？
**A.** IA³ 通过添加额外的神经网络层来适配模型
**B.** IA³ 只引入乘性缩放向量（而非加性更新），参数量极少
**C.** IA³ 需要修改模型架构，无法用于所有模型
**D.** IA³ 等效于对所有权重矩阵应用 LoRA rank=1
**答案：B**
### 解析
- **A 错误：** IA³ 不添加额外神经网络层，传统 Adapter 才是插入额外瓶颈层。
- **B 正确：** IA³ 只引入乘性缩放向量，作用于 K、V 和 FFN 的激活，不是 LoRA 那种加性权重更新；新增参数量极少。
- **C 错误：** 不需要修改模型基础架构，PEFT 库可直接包装使用，支持大量 Transformer 模型。
- **D 错误：** LoRA 是低秩矩阵加性更新，IA³ 是激活乘性缩放，二者数学形式完全不同，不等价。
> **一句话记忆：** LoRA = 加低秩矩阵；IA³ = 乘缩放向量。

### 第 5 题
**题目：** 以下关于 LoRA+ 的改进描述，正确的是？
**A.** LoRA+ 对 A 矩阵和 B 矩阵使用不同的学习率，B 矩阵学习率更高
**B.** LoRA+ 引入了动态 rank 调整策略
**C.** LoRA+ 对所有层使用相同的 rank，但权重不同
**D.** LoRA+ 通过 pruning 去除不重要的 LoRA 参数
**答案：A**
### 解析
- **A 正确：** LoRA+ 核心改进就是对 A、B 矩阵设置不对称学习率，B 矩阵学习率更高（一般 B 的 lr 是 A 的 8~16 倍），标准 LoRA 中 A、B 共用同一个学习率。
- **B 错误：** LoRA+ 没有动态 rank，动态 rank 不属于它的设计。
- **C 错误：** 不是调整每层权重，核心是学习率策略，rank 也不会变。
- **D 错误：** 没有剪枝（pruning）操作，不删除 LoRA 参数。
> **一句话记忆：** LoRA+ = Asymmetric LR，B 学习率 > A 学习率，不改变 rank，不剪枝。

### 第 6 题
**题目：** 在 SFT（监督微调）中，为什么通常只对"回复"部分计算损失而不对"指令"部分计算损失？
**A.** 指令部分的 token 太少，贡献可以忽略
**B.** 避免模型学习生成指令，专注学习如何回复
**C.** 指令部分计算损失会导致过拟合
**D.** 这是 Transformer 架构的技术限制
**答案：B**
### 解析
- **A 错误：** 和 token 数量无关，不是因为 token 少。
- **B 正确：** SFT 数据格式一般是 `指令 + 回复`。如果指令 token 也算 loss，模型会被训练去预测/生成指令；我们目标是让模型读懂指令再输出回答，因此 mask 掉指令部分，仅在回复 token 上计算损失，让模型专注学习如何生成回复。
- **C 错误：** 不是因为会过拟合，核心是学习目标不对。
- **D 错误：** Transformer 没有这个硬性架构限制，是人为设计的训练目标。
> **一句话记忆：** mask 指令 token → 不教模型写指令，只教模型根据指令写回答。

### 第 7 题
**题目：** 以下关于连续学习（Continual Learning）与 LoRA 的结合，最正确的描述是？
**A.** 每个新任务训练一组新的 LoRA 权重，避免互相干扰
**B.** 用相同的 LoRA 权重顺序学习所有任务
**C.** LoRA 本身完全解决了灾难性遗忘
**D.** 连续学习必须使用全量微调
**答案：A**
### 解析
- **A 正确：** 连续学习场景下，为每个任务单独训练一套独立 LoRA，推理时切换对应的 LoRA，不同任务之间互不改动基座权重，避免任务间互相干扰、灾难性遗忘。
- **B 错误：** 同一套 LoRA 顺序学多个任务，会覆盖旧任务信息，引发遗忘。
- **C 错误：** LoRA 不能完全解决灾难性遗忘，只是缓解；基座不变，但如果共享 LoRA 仍然会遗忘。
- **D 错误：** 连续学习不强制全量微调，LoRA 这类参数高效微调正是连续学习常用方案。
> **一句话记忆：** 每个任务存独立 LoRA，基座冻结，切换 adapter 实现多任务，减轻遗忘，但不能根治遗忘。

### 第 8 题
**题目：** 以下哪种技术通过"课程学习"（Curriculum Learning）策略来改善微调效果？
**A.** 随机打乱所有训练数据
**B.** 先训练简单样本，逐步增加难度
**C.** 只训练最难的样本
**D.** 按字母顺序排列训练数据
**答案：B**
### 解析
- **A 错误：** 随机打乱是常规数据 shuffle，不是课程学习。
- **B 正确：** 课程学习（Curriculum Learning）思想：从简单样本开始训练，再逐步引入更难样本，模拟人类循序渐进学习，提升收敛与泛化效果。
- **C 错误：** 只训练最难样本属于难例挖掘，不是课程学习。
- **D 错误：** 按字母排序没有难度递进，不属于课程学习。
> **一句话记忆：** 课程学习 = 由易到难，逐步增加样本难度。

### 第 9 题
**题目：** ORPO（Odds Ratio Preference Optimization）相比 DPO 的关键区别是什么？
**A.** ORPO 需要额外的参考模型进行 KL 约束
**B.** ORPO 将 SFT loss 和偏好对齐 loss 合并为一个目标，无需参考模型
**C.** ORPO 只优化正样本，不惩罚负样本
**D.** ORPO 使用强化学习而非监督学习
**答案：B**
### 解析
- **A 错误：** DPO 才需要冻结参考模型做 KL 约束，ORPO 不需要参考模型。
- **B 正确：** ORPO 核心创新：把 SFT loss 和偏好对齐 loss 合并为单一目标，不需要参考模型，单阶段同时完成指令微调+偏好对齐；DPO 是两阶段（先 SFT，再 DPO 偏好优化）且依赖参考模型。
- **C 错误：** ORPO 同时优化正样本、惩罚负样本，利用 odds ratio 拉大好坏回答差距。
- **D 错误：** ORPO 属于直接偏好优化（类似 DPO，属于隐式奖励的监督式偏好优化），不使用 PPO 这类强化学习。
> **一句话记忆：** DPO = 两阶段 + 要参考模型；ORPO = 单阶段，SFT + 偏好 loss 合并，无参考模型。

### 第 10 题
**题目：** 在评估微调后模型的能力时，"MT-Bench"主要评估什么？
**A.** 数学推理能力（AMC/AIME 级别）
**B.** 代码生成能力（HumanEval）
**C.** 多轮对话的指令遵循和回复质量（LLM-as-Judge 打分）
**D.** 知识密度和事实准确性（MMLU）
**答案：C**
### 解析
- **A 错误：** AMC/AIME 数学推理是 GSM8K、MATH 这类数据集的任务，不是 MT-Bench。
- **B 错误：** HumanEval 是代码评估基准。
- **C 正确：** MT-Bench 是多轮对话评测集，采用 LLM-as-Judge（大模型当裁判），评估模型对话中的指令遵循、逻辑、写作、回复质量，包含多轮交互场景。
- **D 错误：** MMLU 用于评估多学科知识。
> **一句话记忆：** MT-Bench = 多轮对话，LLM 作为裁判打分。

### 第 11 题
**题目：** 以下哪种微调方法不需要训练奖励模型（Reward Model）？
**A.** PPO（Proximal Policy Optimization）
**B.** RLHF 标准流程
**C.** DPO（Direct Preference Optimization）
**D.** 拒绝采样微调（Rejection Sampling Fine-tuning）
**答案：C**
### 解析
- **A 错误：** PPO 属于 RLHF 核心阶段，依赖奖励模型 RM 打分。
- **B 错误：** 标准 RLHF 完整流程包含训练奖励模型，再做 PPO。
- **C 正确：** DPO 直接利用偏好数据优化，不需要单独训练奖励模型，将偏好损失直接嵌入优化目标。
- **D 错误：** 拒绝采样微调需要奖励模型给候选回答打分，筛选高分样本。
> **一句话记忆：** PPO / RLHF / 拒绝采样 → 需要 RM；DPO、ORPO → 不需要单独训练奖励模型。
