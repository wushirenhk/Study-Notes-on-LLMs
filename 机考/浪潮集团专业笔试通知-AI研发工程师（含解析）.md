## 一、简答题

### 第 1 题
**题目：** 简述大模型 Agent 的核心组成组件，并分别说明各组件的核心功能。

**参考答案：**

大模型 Agent 通常由以下五大核心组件构成：

1. **大语言模型（LLM，推理大脑）**
   - 核心功能：作为 Agent 的决策中枢，负责理解用户意图、进行推理思考、拆解任务、生成决策指令和最终回复。

2. **记忆模块（Memory）**
   - 核心功能：分为短期记忆和长期记忆。短期记忆保存当前对话的上下文信息；长期记忆持久化存储历史任务记录、用户偏好和业务知识，支持跨轮次、跨会话的信息复用。

3. **规划模块（Planning）**
   - 核心功能：将复杂的大目标拆解为多个可执行的子任务，制定执行计划；在执行过程中根据反馈进行反思与纠错，动态调整执行路径。

4. **工具模块（Tools）**
   - 核心功能：扩展大模型本身不具备的外部能力，如联网搜索、数据库查询、代码执行、文件操作、API 调用等，是 Agent 与外部世界交互的"手脚"。

5. **感知与执行模块**
   - 核心功能：接收用户输入和工具返回结果，将信息传递给大模型；同时下发工具调用指令，驱动外部工具完成具体操作。

### 第 2 题
**题目：** 对比分析智能体 Agent 与 Workflow 固定工作流的核心差异与各自适用场景。

**参考答案：**

#### 核心差异

| 对比维度 | 智能体 Agent | Workflow 固定工作流 |
|---|---|---|
| **决策方式** | 运行时由大模型自主推理，动态决定下一步动作 | 人工预先定义好全部步骤与分支，执行路径固定 |
| **灵活性** | 可应对未预设的场景，路径可变，适应性强 | 只能处理预先定义好的情况，遇到未预设场景会报错或失效 |
| **稳定性** | 依赖大模型推理，存在一定随机性，结果可能不完全一致 | 确定性高，相同输入每次输出一致，可复现性强 |
| **可控性** | 行为边界较难严格约束，存在不可预期的操作风险 | 步骤完全可控，合规性和安全性易于保障 |
| **实现成本** | 需要大模型 + 工具链 + 记忆系统，搭建和调试成本较高 | 只需编排节点和条件分支，开发简单，维护成本低 |

#### 各自适用场景

- **智能体 Agent 适用场景：**
  - 任务目标模糊、无法提前穷举所有步骤的开放式任务，如市场调研、复杂问题分析、方案规划
  - 需要动态组合多种工具、根据中间结果灵活调整策略的任务
  - 交互性强、需要多轮推理和自主决策的复杂业务场景

- **Workflow 固定工作流适用场景：**
  - 业务流程清晰、步骤固定、要求结果稳定可复现的标准化任务，如审批流程、数据清洗流水线、定时报表生成
  - 对合规性、安全性要求高，需要严格控制每一步操作的场景
  - 高频重复、流程不变的工业化任务，追求执行效率和稳定性

> **实际落地趋势：** 2026 年工业界越来越多项目采用两者混合的方式——确定性环节走 Workflow 保证稳定，复杂研判和决策环节交给 Agent 处理，兼顾稳定性与灵活性。

## 二、选择题

### 第 1 题
**题目：** 元素 1, 9, 2, 5, 6, 7, 4, 3, 8 依次进入栈 G，9 个元素的出栈顺序为 1, 8, 3, 4, 7, 6, 5, 2, 9，在进栈操作时允许出栈操作，则栈 G 的容量至少为（）
A. 6
B. 7
C. 8
D. 9

**答案：C**

### 解析
栈遵循"后进先出"原则，元素必须严格按照给定顺序 `1, 9, 2, 5, 6, 7, 4, 3, 8` 入栈，中途可随时出栈。

逐步模拟：
1. `1` 入栈，随即出栈（第一个出栈元素），栈空。
2. 依次压入 `9, 2, 5, 6, 7, 4, 3`，此时栈内有 **7 个元素**：`[9, 2, 5, 6, 7, 4, 3]`。
3. 压入 `8`，栈内瞬时达到 **8 个元素**：`[9, 2, 5, 6, 7, 4, 3, 8]`，随即弹出 `8`（第二个出栈元素）。
4. 之后依次弹出 `3, 4, 7, 6, 5, 2, 9`，与出栈序列完全吻合。

整个过程中栈内同时存在元素的最大数量为 **8**，因此栈容量至少为 8。

> **关键：** 8 是输入序列的最后一个元素，必须等前面 `9, 2, 5, 6, 7, 4, 3` 全部入栈后才能入栈；而 1 已提前出栈，所以压入 8 时栈内有 7 + 1 = 8 个元素。

### 第 2 题
**题目：** 以下关于分类任务评价指标的公式，错误的是（）
A. 召回率 Recall = TP / (TP + FN)
B. 准确率 Precision = TP / (TP + FP)
C. F1-score = 2TP / (2TP + FP + FN)
D. F1-score = (准确率 × 召回率) / (准确率 + 召回率)

**答案：D**

### 解析
- **A 正确：** 召回率（Recall）= TP / (TP + FN)，衡量实际为正的样本中被正确预测为正的比例。
- **B 正确：** 精确率（Precision）= TP / (TP + FP)，衡量预测为正的样本中实际为正的比例。
- **C 正确：** F1-score = 2 × P × R / (P + R)，代入 P 和 R 的定义化简后即为 2TP / (2TP + FP + FN)。
- **D 错误：** F1-score 的正确公式为 **2 × (准确率 × 召回率) / (准确率 + 召回率)**，D 选项缺少了系数 **2**。

> **速记：** F1 是精确率和召回率的**调和平均数**，调和平均公式为 2ab/(a+b)，必须有系数 2。

### 第 3 题
**题目：** 以下算法中，属于强化学习的是（）
A. 支持向量机（SVM）
B. 线性回归
C. K-Means
D. Q-Learning

**答案：D**

### 解析

- **D. Q-Learning**：属于**强化学习**，通过智能体与环境交互，根据奖励信号迭代更新 Q 值表，学习最优动作策略。

> **记忆点：** Q-Learning、SARSA、DQN、PPO 等都是强化学习算法；名字里带 Q 的基本都是强化学习。

### 第 4 题
**题目：** 以下关于拓扑排序的说法，正确的是（）
A. 有向无环图的拓扑排序序列是唯一的
B. 拓扑排序可用于无向图的最短路径求解
C. 拓扑排序的第一个结点是入度最大的结点
D. 拓扑排序仅适用于有向无环图，常用于表达任务之间的依赖先后关系

**答案：D**

### 解析
- **A 错误：** 有向无环图（DAG）的拓扑排序序列**不一定唯一**。当存在多个入度为 0 的结点时，选择不同的结点会产生不同的拓扑序列。
- **B 错误：** 拓扑排序只适用于**有向无环图**，不能用于无向图；它也不是求解最短路径的算法。
- **C 错误：** 拓扑排序每次选择的是**入度为 0** 的结点，而不是入度最大的结点。
- **D 正确：** 拓扑排序仅适用于有向无环图（DAG），核心用途是表达任务、模块之间的依赖先后顺序，如课程先修关系、编译依赖顺序等。

> **拓扑排序核心步骤：** 不断选入度为 0 的结点输出，删除其出边，重复直到所有结点输出。

### 第 5 题
**题目：** 以下不属于时序（序列）模型的是（）
A. LSTM
B. RNN
C. CNN
D. GRU

**答案：C**

### 解析
- **A. LSTM**（长短期记忆网络）：属于循环神经网络，专门处理时序/序列数据。
- **B. RNN**（循环神经网络）：经典的时序模型，通过隐藏状态传递序列信息。
- **C. CNN**（卷积神经网络）：主要用于提取**空间特征**（如图像），原生不属于时序模型。虽然可以用 1D-CNN 处理序列数据，但 CNN 本身不是为时序设计的。
- **D. GRU**（门控循环单元）：LSTM 的简化变体，同样属于循环类时序模型。

> **记忆点：** RNN、LSTM、GRU 都属于循环神经网络家族，专门处理时间/序列数据；CNN 主打空间特征提取。

### 第 6 题
**题目：** 以下哪个模块用于为神经网络引入非线性能力？（）
A. 卷积函数
B. 随机梯度下降（SGD）
C. 池化层
D. ReLU 激活函数

**答案：D**

### 解析
- **A. 卷积函数**：是线性运算，只做特征提取，不引入非线性。
- **B. 随机梯度下降（SGD）**：是**优化器**，用于更新网络权重，与非线性无关。
- **C. 池化层**：用于下采样、降低特征维度，不引入非线性。
- **D. ReLU 激活函数**：属于**激活函数**，核心作用是为神经网络引入**非线性能力**。如果没有激活函数，无论堆叠多少层网络，都等价于一个单层线性模型，无法拟合复杂的非线性关系。

> **记忆点：** 激活函数负责引入非线性，常见的有 ReLU、Sigmoid、Tanh、GELU 等。

**题目：** 以下哪个属于轻量级、可嵌入的开源向量数据库，常用于 RAG 场景？（）
A. Redis
B. ChromaDB
C. SQLite
D. MySQL

**答案：B**

### 第 8 题
**题目：** 大模型在某些特定类型输入上表现欠佳，以下哪种解决方案最为合适？（）
A. 使用更大的通用数据集
B. 在训练数据中增加这种特定类型的输入样本
C. 改变模型架构
D. 使用更大参数量的模型

**答案：B**

### 解析
模型在特定类型输入上表现欠佳，根本原因通常是该类样本在训练数据中**占比不足或质量不够**，模型没有充分学习到该类输入的模式。

- **A 不合适：** 更大的通用数据集如果没有增加该特定类型的样本，无法针对性解决问题，甚至可能进一步稀释该类样本的比例。
- **B 最合适：** 在训练数据中针对性地增加该特定类型的输入样本，让模型充分学习该类模式，是最直接、最有效的解决方案。
- **C 不合适：** 改变模型架构不是优先方案，问题根源大概率是数据而非架构。
- **D 不合适：** 更大参数量的模型虽然拟合能力更强，但缺少对应类型的训练样本，依然学不好该类输入，且会增加训练和推理成本。

> **核心原则：** 模型表现差，先看数据。特定类型差 → 补特定类型数据，这是最直接有效的思路。

### 第 9 题
**题目：** 已知一棵二叉树的前序遍历序列为 `A B D C E F`，中序遍历序列为 `B D A E C F`，则该二叉树的后序遍历序列为：
A. `B D E F C A`
B. `D B F E C A`
C. `D B E C F A`
D. `D B E F C A`

**答案：D**

### 解析
**遍历规则回顾：**
- 前序（先序）：根 → 左 → 右
- 中序：左 → 根 → 右
- 后序：左 → 右 → 根

**还原过程：**
1. 前序第一个是**根 A**。在中序 `B D A E C F` 中，A 左边 `B D` 是左子树，A 右边 `E C F` 是右子树。
2. **左子树（B、D）：** 前序下一个是 B，所以 B 是左子树的根。看中序 `B D`，B 右边是 D → D 是 B 的右孩子，B 没有左孩子。
3. **右子树（C、E、F）：** 前序中左子树处理完后下一个是 C，C 是右子树的根。看中序 `E C F`：C 左边 E 是左孩子，C 右边 F 是右孩子。

**还原后的树结构：**
```
      A
    /   \
   B     C
    \   / \
     D E   F
```

**后序遍历（左 → 右 → 根）：**
- B 子树：左（无）→ 右 D → 根 B → `D B`
- C 子树：左 E → 右 F → 根 C → `E F C`
- 根 A 放最后

合并结果：`D B E F C A` → **DBEFCA**

### 第 10 题
**题目：** 在样本数量较少但特征维度很高（高维小样本）的场景下，以下哪种模型最为适用？
A. 线性回归
B. 支持向量机
C. 深度学习网络
D. 决策树

> **速记：大量特征 + 少量样本 → SVM**

### 第 11 题
**题目：** 以下关于 Python 中 `*args` 和 `**kwargs` 的说法，错误的是：
A. `**kwargs` 用于接收关键字参数
B. `**kwargs` 会将传入的关键字参数保存为字典
C. `*args` 用于接收可变数量的位置参数
D. 在函数定义中，`**kwargs` 可以写在 `*args` 之前

**答案：D**

### 解析
- A：`**kwargs` 接收关键字参数，正确。
- B：`**kwargs` 把传入的关键字参数保存为字典，正确。
- C：`*args` 接收可变位置参数，正确。
- D：**错误**。函数定义时语法要求 `*args` 必须写在 `**kwargs` 前面，不能反过来。

正确写法：
```python
def func(*args, **kwargs):
    pass
```
如果写成 `def func(**kwargs, *args):` 会直接报语法错误。

> **参数顺序口诀：位置参数 → *args → 默认参数 → **kwargs**

### 第 12 题
**题目：** 一个拥有 1B（10 亿）参数的大模型，使用 bf16 精度存储权重，仅考虑模型权重本身，推理时大约需要多少显存？
A. 1G
B. 4G
C. 2G
D. 8G

**答案：C**

### 解析
- 1B = 10 亿参数
- **bf16（Brain Float16）每个参数占 2 字节**
- 总字节数：$1 \times 10^9 \times 2 = 2 \times 10^9$ 字节
- $1\text{GB} = 1024^3 \approx 10^9$ 字节，所以 1B 参数的 bf16 权重约 **2GB** 显存

> **显存速记表：**
> - FP32：4 字节 → 1B 参数 ≈ 4G
> - BF16 / FP16：2 字节 → 1B 参数 ≈ 2G
> - INT8：1 字节 → 1B 参数 ≈ 1G

题目问模型推理（只算权重），故选 **2G**。

**题目：** 以下算法中，属于强化学习（或大模型强化学习对齐）算法的有：
A. PPO
B. KTO
C. LoRA
D. DPO

**答案：ABD**

### 第 14 题
**题目：** 关于二叉树的重建，以下说法正确的有：
A. 前序遍历和后序遍历总能唯一确定任意一棵二叉树
B. 层序遍历和中序遍历可用于唯一重建二叉树
C. 后序遍历和中序遍历可唯一确定一棵二叉树
D. 前序遍历和中序遍历可唯一确定一棵二叉树

**答案：BCD**

### 解析
**二叉树重建规则：**
1. ✅ **前序 + 中序**：可以唯一确定一棵二叉树。前序第一个是根，在中序中划分左右子树。
2. ✅ **后序 + 中序**：可以唯一确定一棵二叉树。后序最后一个是根，在中序中划分左右子树。
3. ✅ **层序 + 中序**：可以唯一确定一棵二叉树。层序第一个是根，中序划分左右。
4. ❌ **前序 + 后序**：**不能唯一确定二叉树**。当节点存在缺左孩子或缺右孩子时，会得到多棵不同的二叉树。

逐项判断：
- A：前序和后序总能确定任意二叉树 → **错误**，无法区分左右子树。
- B：层序和中序可唯一重建 → **正确**。
- C：后序和中序可唯一确定 → **正确**。
- D：前序和中序可唯一确定 → **正确**。

> **记忆口诀：必须要有中序序列，搭配前序 / 后序 / 层序就能唯一重建；只有前序 + 后序不行。**

### 第 15 题
**题目：** 关于 A* 搜索算法，以下说法正确的有：
A. 若启发函数不满足可采纳条件（高估真实代价），会破坏 A* 的最优性保证
B. 一致（相容）启发函数满足三角不等式：h(n) ≤ c(n,n') + h(n')
C. 当 h(n) ≡ 0 时，A* 算法等价于 Dijkstra（一致代价搜索）
D. 可采纳启发函数的定义是永远不会高估节点到目标的真实剩余代价，即 h(n) ≤ h*(n)

**答案：ABCD**

### 解析
- **A ✔**：启发函数如果不满足可采纳条件（高估真实代价），**会破坏 A* 的最优性保证**，可能找不到最优路径。
- **B ✔**：一致（相容）启发函数满足三角不等式：$h(n) \le c(n,n') + h(n')$。
- **C ✔**：$h(n) \equiv 0$ 时，估价函数 $f(n) = g(n)$，A* 就等价于 Dijkstra（一致代价搜索）。
- **D ✔**：**可采纳启发函数定义**：永远不会高估节点到目标的真实剩余代价，$h(n) \le h^{*}(n)$。

> **总结记忆：**
> 1. 可采纳：不高估，保证最优；
> 2. 一致（相容）：满足三角不等式；
> 3. h = 0 → A* = Dijkstra；
> 4. h 高估 → 失去最优性。

### 第 16 题
**题目：** 关于程序性能优化与缓存，以下说法正确的有：
A. 减少不必要的对象分配有助于降低运行时开销
B. 链表的随机访问一定比数组更快
C. 分块处理（Tiling）可以改善缓存命中率
D. 连续数组访问通常比随机指针跳转具有更好的局部性

**答案：ACD**

### 解析
- **A ✔**：频繁创建和销毁对象会带来内存分配和 GC（垃圾回收）开销，减少不必要的对象分配可以降低运行时开销。
- **B ❌**：链表随机访问需要遍历，时间复杂度 O(n)；数组随机访问 O(1)。链表随机访问比数组慢得多。
- **C ✔**：分块（Tiling / 分块算法）把大的数据切小，让数据可以全部放进 CPU 缓存，减少 cache miss，提升命中率。
- **D ✔**：数组内存连续，具备**空间局部性**；链表指针跳转是随机内存访问，局部性很差，缓存失效多。

> **小结：** 缓存友好的核心是尽量连续内存访问、分块处理、减少频繁对象创建；链表不擅长随机访问。

### 第 19 题
**题目：** 在检索增强生成（RAG）中，以下哪项不属于重排序（Re-Ranking）模块的作用？
A. 对模型最终生成结果进行评分
B. 生成最终答案
C. 对检索结果按相关性进行重新排序
D. 增加检索到的文档的数量

**答案：ABD**

### 解析
- **C 属于 Re-Ranking 的作用**：重排序就是把初筛检索出来的文档，用更强的模型重新打分，按相关性重新排序，挑选最相关的文档送入大模型。
- **A 不属于**：Re-Ranking 只处理检索回来的文档，不对大模型**输出的生成答案**做评分。
- **B 不属于**：生成最终答案是大模型（LLM）的任务，不是重排序模块做的。
- **D 不属于**：重排序**不会增加文档数量**；它是在已检索出的文档集合内部重排，可过滤掉部分文档，但不会新增文档。

> **总结：** Re-Ranking =「在已有候选文档集合内做相关性重排筛选」，不新增文档、不打分回答、不生成答案。

### 第 20 题
**题目：** 关于并查集（Union-Find）数据结构，以下说法正确的有：
A. 路径压缩与按秩合并后，均摊时间复杂度接近 O(α(n))（阿克曼函数反函数，近乎常数）
B. Kruskal 最小生成树算法中使用并查集来判断是否形成环
C. 普通并查集不支持在线删边操作
D. 并查集不适合处理集合合并与连通性查询问题

**题目：** 贪心算法每一步都做出局部最优选择，因此一定能得到全局最优解。
A. False
B. True

**答案：A（False）**

### 解析
贪心算法每一步做**局部最优选择**，但**不一定得到全局最优解**。

只有当问题满足**贪心选择性质**和**最优子结构**时，贪心才能得到全局最优解。很多场景下局部最优会导致全局次优甚至错误。

**反例：**
- 部分背包问题的特定场景
- 找零钱问题的特定币值组合（如币值 1、3、4，找 6 元：贪心选 4+1+1 = 3 枚，最优是 3+3 = 2 枚）

因此题干说法错误。
